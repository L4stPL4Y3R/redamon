# This is public, well-known ecosystem data, not scan output and not target
# data. It is deliberately a hand-maintained shortlist rather than a scraped
# top-N: the check reports a name that is 1-2 edits from an entry here, so every
# addition widens what can be flagged. A short, high-confidence list produces
# far fewer false positives than a long tail of rarely-typed names.

# Rules for editing:
#   - one lowercase name per line, '#' comments and blank lines ignored
